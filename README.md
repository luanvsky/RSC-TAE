

# Sistema de Reconhecimento de Saberes e Competências (RSC-TAE)

> Sistema web desenvolvido para otimizar, gerenciar e dar transparência aos processos de solicitação e avaliação do Reconhecimento de Saberes e Competências (RSC) para os servidores Técnico-Administrativos em Educação (TAE).

---

## 🚀 Sobre o Projeto

O **RSC-TAE** surge como uma solução para modernizar os trâmites associados à concessão de RSC nas Instituições Federais de Ensino. A plataforma atua simplificando a submissão de documentos comprobatórios pelos servidores, agilizando o trabalho das comissões avaliadoras e oferecendo maior controle gerencial para as áreas de gestão de pessoas.

---

## ✨ Principais Funcionalidades

- **Painel do Servidor:** Acompanhamento em tempo real do status da solicitação, submissão guiada de portfólio de atividades e histórico de níveis concedidos.
- **Módulo de Avaliação:** Interface dedicada para as comissões examinadoras realizarem análises, pontuações e emissão de pareceres técnicos fundamentados.
- **Painel Gerencial / PROGEP:** Métricas consolidadas de processos em andamento, controle de prazos e relatórios estatísticos.

## ⚙️ Como Executar o Projeto

Siga os passos abaixo para configurar e executar o ambiente de desenvolvimento localmente:

### Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- Git
- *(Insira dependências necessárias, ex: Node.js >= 18 ou Python >= 3.10)*

### Instalação

1. Clone o repositório:
   ```bash
   git clone [https://github.com/luanvsky/RSC-TAE.git](https://github.com/luanvsky/RSC-TAE.git)

```

2. Acesse o diretório do projeto:
```bash
cd RSC-TAE

```


3. Instale as dependências:
```bash
# Exemplo para Node.js
npm install

# Ou exemplo para Python/Pip
pip install -r requirements.txt

```


4. Configure as variáveis de ambiente (crie um arquivo `.env` baseado no `.env.example`).
5. Execute a aplicação:
```bash
# Exemplo para iniciar o servidor de desenvolvimento
npm run dev

```
